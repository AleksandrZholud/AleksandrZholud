# Hi, I'm Alex 👋 
### Senior Software Engineer | Backend Architect | Team Lead

I am a passionate engineer with **8 years of professional experience** in building robust backend systems and leading development teams. My journey began in 2018, and since then, I have evolved from a developer into an architect and leader who focuses on creating scalable, high-performance solutions that actually solve real-world problems.

Based in **Bergen, Norway** 🇳🇴

---

### 💻 What I do
*   **System Architecture:** I design complex backend environments using **Java, Kotlin, and Go**, focusing on microservices, reliability, and clean code principles.
*   **Team Leadership:** I don’t just manage tasks; I mentor developers and optimize engineering processes to help teams deliver quality software efficiently.
*   **Performance Engineering:** I have a deep interest in database optimization (SQL/NoSQL) and system tuning—making slow systems run fast is what I do best.
*   **Full-Cycle Development:** From initial server configuration and CI/CD pipelines to the final API endpoint, I take ownership of the entire lifecycle.

---

### 🛠 Technical Stack

*   **Languages:** Java (Spring Boot, JPA, JDBC), Kotlin, Go, Groovy, Node.js.
*   **Databases:** PostgreSQL, MS SQL Server, MongoDB, Liquibase/Flyway.
*   **Infrastructure:** Docker, Kubernetes, Kafka, CI/CD (Jenkins, GitLab CI, GitHub Actions).
*   **Observability:** Prometheus, Grafana, Splunk, Datadog.

### 🌟 Beyond the Code
